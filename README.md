# XMod

## About

XMod is a physics sandbox game where you can build anything you can imagine.

## Getting Started

1. Download the latest release from [itch.io](https://oramix.itch.io/xmod)
2. Extract the archive
3. Run the executable

> **Note:** macOS and Linux aren't supported. Play using WINE.

## Modding

XMod supports community mods.

Place mods in the following folder:

`C:\Users\%USER%\AppData\LocalLow\OramiX\XMod\Mods`

> **Note:** AppData (on Windows) is hidden by default.
> Enable **Show hidden files** in Folder Options.
